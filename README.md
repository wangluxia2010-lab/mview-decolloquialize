1. 从仓库下载 `skill/steno-decolloquialize.skill`
2. 在千问办公对话里把这个文件拖进去，点卡片上的**「保存技能」**
3. 之后说一句「去口语化」或「把这份速记改书面」即可自动按标准执行

## 方法论速览

**核心定义**：去口语化不是把话说文绉绉，而是把"为耳朵写的文字"改造成"为眼睛写的文字"，同时一个事实都不丢。三件事——**删噪音 → 立结构 → 保真值**。

**最重要的一条纪律：先分角色，再动手。**

| 角色 | 干预级别 | 原则 |
|---|---|---|
| 己方与客户高管 | 重写级 | 彻底书面化（可能对外引用） |
| 媒体/外部嘉宾 | 保真级 | 只修错字与断句，实质内容一个不能少 |
| 主持人串场 | 功能级 | 压缩为邀请句，删无信息附和 |

**六步工作流**：①双引擎转写（钉钉AI听记＋豆包）→ ②各自与四类书面文件比对（媒体名单/主持人串场词/客户讲话稿/原确认文件）→ ③千问办公统一整合 → ④分角色去口语化 → ⑤第二次与书面文件比对 → ⑥人工核查定稿。

**版本纪律**：任何交付物有任何修改——哪怕一个字——都必须更新版本号（文件名、封面标注、版本记录表三处同步）。
